# FoodCompany - Presentación Interactiva

Presentación interactiva HTML para el simulador de negocios **FoodCompany** de CompanyGame.

## Uso

1. Abrir `index.html` en cualquier navegador moderno
2. Navegar con las flechas laterales o las teclas ← →
3. Hacer clic en los indicadores de progreso para saltar a un slide

## Estructura

- `index.html` — Presentación completa (HTML/CSS/JS)
- `CLAUDE.md` — Documentación técnica para Claude Code
- `README.md` — Este archivo

## Créditos

- **Simulador**: CompanyGame (companygame.com)
- **Distribución Colombia**: Simuladores de Negocios Colombia / Grupo Edutec
- **Tipografías**: Google Fonts (Montserrat, Open Sans)
